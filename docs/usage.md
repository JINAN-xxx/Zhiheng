# 使用与操作

本页说明平台配置、日常使用与已接纳任务的恢复。部署和迁移步骤见[部署指南](deployment.md)。

## 模型、定价与开发调用

1. 有权人员先在“凭据管理”创建连接，再在“模型目录”接入模型。两者独立授权，模型目录不提供凭据管理入口。新增、编辑及重新启用模型前会校验服务商连接、API Key 和模型标识；校验失败不保存，期间连接发生变化需重新校验。模型启用且连接可用后即可使用，模型目录不再区分发布状态。
2. 对话体验、知识库、智能助手、工作空间和外部 API 按模型类型选择已启用模型；管理员或有 `platform:models:test` 的账号还可在模型目录独立试用。角色还须启用该模块并具备查看权限。外部 API 仍须具备账号操作权限和 Key 的对应授权。
3. 积分计费关闭时，不校验积分余额、模型费率、累计 Token 额度及 Key 的 Token／金额／积分预算，不新增这些预占或扣费。Token 仅记录服务商报告的实际消耗；用量未知时保留未知事实，不估算扣账。身份、资源授权、Key 请求频率和并发限制继续生效。历史配置和账本保留，后续重新启用时按原规则复核。
4. 启用积分前，为已启用模型配置积分价格，免费也应明确标记，再发放积分。模式切换等待在途工作结束。
5. 智能体 API 抽屉从后端读取发布配置的完整模型依赖，包括实际生效的重排模型，再创建 Key。切换默认重排后，旧 Key 需要重新核对授权；刷新抽屉可查看当前完整要求。

模型输出配置不再使用统一的 131072 Token 上限，只接受可精确传输的正整数，并使用 64 位数据库字段存储。实际生成仍受服务商和具体模型能力限制；聊天输出长度留空时不向服务商发送长度上限，配额和计费治理继续生效。

## Token 额度与未知用量

- 用户在“用量与调用 → 历史 Token”查看自己的完整分页台账，筛选在服务端执行，包含知识索引、知识检索和图谱。
- 启用积分与额度管理模块且有 `ai:credits:read` 的人员，可从“用量与调用 → 用户积分 → Token 额度”查看指定用户的台账。
- 调整累计额度需要 `ai:credits:configure`，核对未知 Token 需要 `ai:credits:reconcile`；两者还须有该模块的启用与查看权限。调额不清零历史用量，不可低于已使用与预占之和。安装配置中的 Token 默认值只用于创建新账户，已有账户须显式调额。
- 历史 Token 模式中已冻结的未知调用继续保留原预占；当前关闭计费后接纳的新调用不新增 Token 或积分预占。管理员核实供应商用量后，点“核对用量”补充未知事实；确认执行前拒绝才可释放已有预占为零。已报告的事实不可覆盖。
- 积分调用继续在“积分明细”核对；按调用发生时冻结的模式处理，不根据当前开关猜测历史调用的模式。
- 写入有版本检查、稳定请求标识及审计。网络结果未知时沿用原提交，不自动重建新命令。

## 知识库、分享与上传恢复

- 新知识库使用独立资料副本，成员按库级权限使用和查看、下载全部库内资料，不再依赖原附件的逐资料授权。旧库迁移需所有者预览访问变化并确认。
- 仅支持邀请链接。接收人登录后明确接受；所有者可撤销邀请和移除成员。没有平台账号搜索或全员共享入口。
- 主检索固定执行向量/混合召回和必需重排。单库最多 40 个候选、联合最多 80 个，成功结果最多 8 条；长资料按冻结的预算分批重排，所有批次完成后才发布结果，失败不返回未经重排结果。
- 在“资料 → 添加资料”重新打开上传面板，会发现当前库、当前文件夹中仍有效的待导入原文。每批恢复最多 20 个，完成后可继续下一批；也可取消清理。服务端暂存保留 24 小时。权限变化、已导入、已取消或过期的内容不会作为可恢复批次继续使用。
- Embedding 的真实绑定变化仍需显式重建；仅更换重排不重建索引。

## 智能助手与 Work 恢复

- 从侧栏“智能助手”进入本人助手，发布后点击“使用”创建正式会话。私人发布无需应用；对外 API 调用仍需绑定应用及相应 Key 授权。
- 正式会话支持历史读取、继续提问、停止及恢复观察；重新发布后，新消息采用最新发布配置，历史回复和已接纳运行不改写。
- 会话按用户和助手隔离，不混入其他会话历史；细节见[智能助手会话](api/assistant-conversations.md)。

- 智能体创建使用稳定请求标识。响应丢失时，界面保留原配置并提供确认原提交的路径；重复确认返回同一对象，不重复创建。
- 已完成或归档的工作允许修复成员，历史消息和历史冻结配置保留。可先替换失效成员，再重新打开。重开仍校验当前全部有效成员的模型、技能和知识访问。
- 已归档工作有“重新打开”入口；执行仍只允许在活动状态进行。
- 当前 Work 是人工指定成员接力；自动规划、工具执行和结构化输出尚未提供；文档解析与 OCR 通过[本地及云端 MinerU](architecture/document-parsing.md)接入。

## 权限变化

前端在导航超过缓存时效、页面重新聚焦时检查当前身份；遇到 403 会立即重新验证。权限变化会结束当前受保护页面的展示，按当前有效权限进入可访问页面；没有可用功能时显示功能访问页。后端始终逐请求复核权限。

角色采用模块开关与独立操作授权，关闭模块会保留子操作设置，但不再生效。多个角色仅合并各自有效的授权。模型目录不开放凭据，开发接入的 Scope 不扩大角色权限。知识库默认配置与文档解析的保存需要系统参数“编辑”权限，不能以参数“新增”替代。完整规则见[模块与操作权限](api/platform-module-permissions.md)。

## 技能市场与个人技能

“技能”页面提供“市场”和“我的”两个分类：

- 市场展示平台预制技能，可查看内容并按当前账号启用或停用；预制技能不能删除或通过上传替换。
- 我的展示本人上传的技能，支持上传 SKILL.md 或 ZIP 技能包、预检确认、替换、启停与删除。
- 上传包的名称标识不能覆盖预制技能；需修改包中的名称标识后作为个人技能安装。
- 对话和智能体的技能选择继续包含已启用的市场技能与个人技能，历史发布和运行快照保留。

升级会恢复旧版本中删除的预制技能，使其在市场可见；恢复项默认停用，由用户自行决定是否启用。个人上传、技能正文和历史引用不改变。
