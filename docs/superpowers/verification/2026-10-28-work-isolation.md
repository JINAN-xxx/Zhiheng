# 工作空间独立入口验收

2026-10-28。用户明确工作空间与普通聊天分开，本轮已在 <http://127.0.0.1:19080/work> 源码运行实例生效。

## 当前行为

- 工作空间只展示工作目标、智能体成员、任务历史与执行状态，不再包含聊天/工作切换。
- 工作与对话体验分别从主导航进入。直接打开 `/work` 或旧地址 `/ai/chat/work` 不再初始化普通聊天历史；旧地址仍高亮工作空间。
- 普通聊天仅在进入聊天路由时加载自己的模型和会话列表。保留原有切页清理、状态提供器与工作请求保护，没有修改任务或聊天的持久化结构。
- 工作任务继续使用 `/api/work` 接口及独立的 `work_turn` 运行资源，不把工作目标填入普通聊天输入。

首次浏览器组合运行中，新增导航用例误要求普通聊天草稿跨页保留，而基线 `ChatView` 卸载时会清空当前会话。该断言不属于本轮需求，已改为验证工作目标不会进入普通聊天输入；保留基线清理逻辑，单例复测通过，其余 23 项原运行通过。原始日志完整保留，不将首次运行记为零失败。

正常实例没有新建任务、发送消息或调用付费模型；任务执行链路由浏览器接口夹具回归覆盖。本次未构建安装包或镜像。原始失败、通过日志、正常页面截图和只读核对结果位于工作区外 `work-isolation/20261028`。

后台管理尚未迁入当前新平台：原用户、角色、部门、菜单、字典、系统配置及日志管理保留在 `legacy`。这属于独立的功能缺口，本轮不将其描述为已恢复，README 已明确标注。
