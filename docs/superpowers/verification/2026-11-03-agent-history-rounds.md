# 智能体上下文轮数验收

2026-11-03，功能提交 `a80c57c0` 已同步至当前平台。开发者在“智能体 → 配置 → 模型与发布 → 上下文轮数”选择 0～20，默认 20。

- N 轮表示最近 N 组历史问答加当前问题；0 只发送当前问题。系统提示词、技能、知识检索与工作空间任务目标仍保留。
- 保存后用于草稿调试，发布后用于公开 API；工作空间使用成员加入时冻结的发布配置。调整轮数保留页面显示历史，旧配置缺字段时读取为 20，无数据库迁移。
- 轮数不会改变已经受理的请求快照及重放结果。智能体不自动生成摘要，普通对话既有 30/15 策略不变。
