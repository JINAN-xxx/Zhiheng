# 统一白色界面验收

用户要求关闭主题切换、减少大块模块卡片，并明确选择整页白色。本轮在当前 VS Code 根目录和源码实例落实，分支 `refactor/white-console-ui`，入口仍为 <http://127.0.0.1:19080>。

## 视觉与行为

- 导航、页头和主内容共用白色底色；公共面板移除外框、圆角和叠加底板，主要依靠文字层级、间距及细分隔线组织内容。
- 智能体、技能、模型和知识库的资源卡片改为轻量内容行，保留名称、描述、状态和操作。工作台指标、用量、文件统计、后台状态去掉各自的大块卡片。
- 编辑器、模型接入、API 文档、工作目标、知识检索与文档页面减少外框套层；输入、选择、焦点、状态和弹层保留必要的识别反馈。
- 主题入口、自动深色选择、深色配置与无调用者样式移除；启动时清理原主题偏好，页面及原生控件固定浅色。聊天 Markdown 显式使用浅色，图谱不再监听主题切换。
- 登录和分享页面沿用白色画布。品牌、系统字体与蓝紫主色保持当前约定。
