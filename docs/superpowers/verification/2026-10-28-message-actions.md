# 消息操作与源码运行验收

2026-10-28，聊天消息操作已接入正式平台。按用户最新要求，当前以源码挂载运行，入口仍为 <http://127.0.0.1:19080>；后续前端修改由 Vite 热更新，API 使用源码自动重载，Worker 修改后执行 `./dev.sh restart-worker`。

## 当前行为

- 对话欢迎页移除“聊天/工作”切换，工作入口保留在主导航。
- 最新一轮回复可重新生成。原提问不重复，原回复保留，新调用生成独立 Run 和用量；可切换查看回复版本。上下文每轮只使用最新完整回复，失败或停止的部分正文仍可保留、查看、再次生成。每题最多 100 版，消息读取按完整回合限制窗口，不删除旧数据。
- 赞与踩互斥、可取消，按消息和用户持久保存；刷新后读取服务端状态。已确认的新反馈不会被先前开始读取的旧历史响应覆盖。
- 朗读接入浏览器语音，支持停止、切换消息互斥及离开时清理。浏览器不支持或播放失败时给出实际原因，不伪装已播放。
- 分享先预览再手动创建，可附带提问，默认 7 天、最长 30 天；匿名只能读取冻结的提问/回复文本，链接可撤销，源会话删除或用户禁用后不可读。分享内容不包含附件、知识来源元数据和隐藏推理。对方需要能够访问该平台部署地址。
- 分享令牌仅存哈希，API/Nginx 的分享路径、查询、Referer 和异常日志均脱敏；公开页面/接口禁止缓存及索引，并设置 Referrer Policy。

## 数据与运行方式

当前数据库版本为 `0009_message_actions`。新增消息关联/版本/请求选择列，以及反馈和分享表。升级前已保存数据库、配置和服务身份；实际正常实例迁移前后 60 张原表的原始字段/数据指纹一致。原模型配置和凭据保留，原有 55 份未提交优化文件哈希未变。

源码模式复用现有依赖镜像，不以重新打包作为每次修改的前置步骤。后端和 Worker 从 `/app/src` 加载当前代码，迁移目录显式挂载；前端通过 Node 24/Vite 源码服务，由原 `19080` 网页入口代理。开发覆盖配置在 `deploy/core/compose.source.yaml`，生成的 Nginx 配置位于已忽略的 `deploy/core/.source/`。

```bash
# 默认沿用正在运行的 Core 实例配置
./dev.sh up

# 显式迁移数据库；改动 Worker 代码后重启
./dev.sh migrate
./dev.sh restart-worker

# 观察服务
./dev.sh logs -f api worker ui-source web
```

数据库迁移不由 API 自动重载执行。`deploy.sh` 仍是镜像发布入口，当前开发运行使用 `dev.sh`。备份和验证证据私密保存在本机 `message-actions/20261028` 目录，凭据、令牌和原始数据不提交到仓库。
