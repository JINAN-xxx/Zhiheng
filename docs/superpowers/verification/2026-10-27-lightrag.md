2026-10-27，`refactor/ai-core-modularization`。图谱已部署至本机正常实例 <http://127.0.0.1:19080>，schema 为 `0008_graph`。原管理员登录、12 个接口、七个页面、向量和图谱能力均复查通过。旧项目恢复的一份硅基流动连接和四个模型保留，详情见[模型服务恢复](2026-10-27-model-service-restoration.md)。MinerU 继续暂缓。

## 交付范围

图谱属于内置 knowledge 模块，固定 `lightrag-hku==1.5.7`，使用专属 PostgreSQL schema 和三类 Milvus 集合。LLM/Embedding 回调进入平台统一 Run、outbox、配额及用量账本，模型接入仍为 LangChain 1.4.7，没有恢复 LiteLLM 运行服务。官方 SDK 源码保持原字节，离线 BPE 随 wheel 安装。

原页面支持配置、试构建、正式构建、任务状态、取消、画布、labels/subgraph 和带来源的上下文查询。试构建不发布；正式构建完成后才切换活动版本，失败保留旧图。支持 mix/local/global/hybrid/naive 查询，当前返回检索上下文；Chat、Agent、Work 与公开智能体的知识组合使用既有向量检索。

来源保留原文、解析产物、文档/索引 revision、chunk ordinal 和摘要。图谱聚合读取及历史按当前库权限和该版本全部原文权限复核。管理员代构建使用库所有者的来源权限与用量，查询按实际调用者计费，查询历史按调用者隔离。

## 明确限制

- Python 3.13 原整套保留一个失败，当前以透明的同源有效补测组成覆盖，不能宣称单次全绿。
- 应用 epoch 是执行权检查，不能原子撤回远端已接受的 I/O。未知 writer 或真正不合作扩展继续保持隔离，GC 仍检查活动指针、pin、真实停止证明和 tombstone。
- 图谱抽取效果和生产负载未验收；本轮实际图谱链使用本地模型协议服务。
- 上传取消请求的必需空 JSON 体已修复，实际返回 204 并释放引用。整个浏览器关闭后，未导入批次仍不能自动恢复，原文和暂存引用保留；服务端批次发现与恢复列为后续改进，退出前应完成导入或确认取消。
- MinerU 仅完成本机部署准备，模型未下载、服务未部署、实际 OCR 未验收，本轮按用户要求跳过。
