# 登录页验收

按用户选择采用左右布局：左上角保留智衡品牌，左侧用现有标识和静态几何图形，右侧为账号密码表单。整页延续白色底色、蓝紫主色和系统字体，通过留白组织区域。输入框和主按钮高度为 48px，窄屏隐藏装饰图形并切换单列，短窗口可正常滚动。

移除外围登录卡片、不可操作的“记住密码”和旧英文页脚，保留中文标签、必填/认证错误、密码显隐和请求中状态。请求期间禁用输入，重复提交仍由原逻辑保护；认证接口、成功跳转、取消请求和密码清理沿用原实现。

| 检查 | 结果 |
| --- | --- |
| 登录回归 | 原 4 项登录用例与知识上传重新登录恢复，共 5 项通过，涵盖必填、点击/回车、失败重试和密码不落盘 |
| 响应式 | 1440×900、1024×768、390×844、320×568、844×390、1280×600 均无横向溢出，登录按钮可访问 |
| 正常实例 | 原管理员用回车实际登录并进入对话页；可见标签、键盘顺序、密码显隐及本地存储检查通过，无页面/API 异常和额外业务写入 |
| 规范 | 全前端严格类型、ESLint、Prettier 及最终两份 Vue 文件格式复查通过 |
| 独立审查 | 额外复核 900/901px 分界、手机/短屏、请求中禁用、防重复提交、失败清空密码与重试跳转，无剩余问题 |
| 原优化保护 | 原 57 份文件哈希不变 |

旧登录测试只更新已移除“记住密码”的断言。初轮有页面停留加载状态的超时记录；最终附页面/请求诊断的 5 项串行回归在原等待阈值下通过，日志保留，未改动平台加载逻辑。该结果限定于上述登录交互及源码实例，不作为加载性能验收。
