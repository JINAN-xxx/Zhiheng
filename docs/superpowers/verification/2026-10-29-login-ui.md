# 登录页验收

按用户选择采用左右布局：左上角保留智衡品牌，左侧用现有标识和静态几何图形，右侧为账号密码表单。整页延续白色底色、蓝紫主色和系统字体，通过留白组织区域。输入框和主按钮高度为 48px，窄屏隐藏装饰图形并切换单列，短窗口可正常滚动。

移除外围登录卡片、不可操作的“记住密码”和旧英文页脚，按用户后续要求再去除“使用账号继续”和“账号由管理员分配”。保留中文标签、必填/认证错误、密码显隐和请求中状态。请求期间禁用输入，重复提交仍由原逻辑保护；认证接口、成功跳转、取消请求和密码清理沿用原实现。

“保存密码”默认不勾选，选中后仅在服务端认证成功时请求浏览器密码管理器保存，不阻塞跳转，不把密码写入平台 localStorage、sessionStorage 或 Cookie。能力缺失、非安全/嵌入上下文及保存失败均降级；失败提示按同一登录身份隔离。实际保存由浏览器与用户决定，参见 [MDN 保存凭据说明](https://developer.mozilla.org/en-US/docs/Web/API/CredentialsContainer/store)。“忘记密码”弹窗提供已有的“后台管理 → 用户管理”重置指引，关闭后保留输入。
