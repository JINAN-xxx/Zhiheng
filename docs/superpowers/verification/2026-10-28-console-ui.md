# 控制台 UI 接入验收

2026-10-28，用户确认的控制台设计已接入正式 Vue 前端，并在本机正常入口 <http://127.0.0.1:19080> 启用。实现分支为 `feat/bailian-console-ui`，设计参考保留在 `frontend/design-previews/bailian/`，正式代码位于 `frontend/src/`。

## 实现范围

- 统一系统字体、蓝紫色主题、白色导航、浅灰页面、面板、表单与桌面/手机布局，保留浅色/深色主题。
- 新增读取真实接口的工作台与资源搜索；模型、智能体、知识库、技能分别处理加载和失败状态，保留管理员入口限制。
- 对话与工作使用各自的历史栏，保留会话/任务生命周期、运行停止恢复、技能、附件、来源与冻结成员。提问靠右、模型回复靠左，双方可复制完整原文；模型回复下方采用用户参考图的灰色图标栏。
- 智能体使用完整配置页与右侧试聊，保留十项配置、草稿和发布版本分离、未保存保护及 API 说明。技能保留正式的 SKILL.md/ZIP 预检、解析确认安装、内容、启停和引用保护。
- 模型、连接、费率、应用、密钥、调用与用量、知识文档、检索、图谱和文件治理统一视觉，继续使用原有 API、权限与业务状态。
- 补齐已有后端支持的受管文件导入和原文下载入口。未知导入按用户/知识库保存完整请求，刷新后手动确认原提交；成功及明确失败清理记录，未知状态保留原请求身份。
- 初始路由就绪后再挂载应用，防止目标页面尚未加载时提前操作导航。该问题有延迟路由资产的确定性失败/通过验证。

页面回归在独立的待发布 Nginx 镜像上运行，HTTP/SSE 业务边界使用夹具，不调用真实模型供应商。正常入口检查使用真实认证和只读 API，唯一 POST 为管理员登录；没有新建业务测试数据或触发推理。部分并行首屏等待失败未能稳定复现，其原始日志、完整请求轨迹和定向复测均保留，未把等待超时归因为已证明的负载问题。

密钥轮换宽限期显示已改为中性状态说明，避免把 API 创建的不同宽限期误写成固定 24 小时。未实现的重新生成、赞踩、朗读和分享图标保持禁用并提供原因；复制可用。知识文档/文件夹移动需要新增后端契约，本轮仅呈现当前真实支持的操作。MinerU 继续暂缓接通。

## 启用与恢复

正常网页镜像为 `zhiheng-core-web:console-20261028`，ID 为 `sha256:8ae1070b4eb905ca581584c0cf1ed4a0bea6a98c0a1a0af5b896e52153c8fd8b`。只更新当前部署配置的 `CORE_FRONTEND_IMAGE`，通过 `up --no-deps --no-build web` 启用；没有数据库迁移，也没有更新 API、worker 或审计实例。

原网页镜像 `zhiheng-core-web:graph-20261027` 与切换前配置私密备份保留。恢复时将当前部署配置中的前端镜像设回原标签，再仅更新 web 服务。源码 Docker 构建曾遇到 npm registry 连接重置；实际交付使用已通过本机检查的构建产物打包进已缓存的 Nginx 运行镜像，并逐文件核对。

完整日志、失败基线、独立审查、源码/产物哈希与正常入口截图私密保存在本机 `ui-integration/20261028` 验收目录，凭据和用户数据不进入仓库。实现步骤见[接入计划](../plans/2026-10-28-console-ui.md)。
