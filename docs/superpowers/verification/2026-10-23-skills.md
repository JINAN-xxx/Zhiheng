| 验收项 | 实际行为 |
| --- | --- |
| 两阶段安装 | 原始 ZIP/主文件预检只生成 owner 草稿，确认后原子安装；同草稿并发与重复确认幂等，已确认事实不因过期清理消失 |
| 存储与版本 | 原包 BYTEA、包 SHA、带长度边界的文件树摘要、不可变内容修订；状态整数 CAS 与包元数据版本独立 |
| 包边界 | 上传10MiB、解压30MiB、200文件、主文件128KiB；根文件/UTF-8/YAML校验；拒绝危险路径、链接、特殊/加密/重复文件、非空目录与损坏压缩流 |
| 字符边界 | 合法 ASCII slug 1–255，中文搜索正常；NUL、无效 UTF-8、孤立代理字符稳定拒绝，无 Run/账本/供应商副作用 |
| 管理与内容 | 原卡片/上传/详情布局保留；正文纯文本；停用后删除，builtin 禁止删除；旧内容与消息摘要保留 |
| 聊天 | 按钮或末尾 @ 选择最多5项，顺序保留、主文件总量32KiB；接纳时冻结全文并计入预留，消息保存 revision/hash/name/slug |
| 幂等与异步 | 发送意图复制技能列表，原请求重试保持原输入；换会话/资源/账号、关闭窗口后拒绝晚响应；离开页面销毁删除确认 |

`skills` 只从自身模块公开值对象；聊天由 application 通过 `skills.public` 编排。没有插件扫描、任意脚本执行或另一条模型 SDK 调用路径。API 和 worker 不建表或隐式种子；两个 builtin 由迁移显式写入，worker 每批最多100条清理过期未确认草稿。
