## 健康检查修复

Nginx 原先将 `/health/live` 和 `/health/ready` 当作网页地址回退到 `platform.html`，即使 API 不就绪也返回 HTML 200。现在这两个精确地址代理到实际 API，保留 JSON 状态与上游错误码。

独立增量规格审查通过 52 项真实 HTTP 检查；独立质量审查通过 59 次请求、77 项断言。覆盖 JSON 200/503、连接拒绝 502、连接及读取超时 504、原 API/公开接口/文档路由、SSE 和网页回退。没有把旧前端业务测试重复归为本配置增量的执行结果。

先更新隔离验收实例，再更新正常实例的网页配置层。588 个原界面文件逐字节一致，API、worker、PostgreSQL、Redis 的容器身份和镜像保持原样；原网页镜像保留为回退版本。
