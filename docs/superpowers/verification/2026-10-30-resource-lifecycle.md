# 资源生命周期验收

用户要求修复[排查清单](../reviews/2026-10-30-resource-lifecycle.md)中的全部问题。本轮在 `fix/resource-lifecycle` 隔离分支实现，正常实例原数据与 57 份未提交优化受到保护；复用现有缓存依赖和源码运行方式，不打包、不安装 SDK。

## 行为变化

- 内置与上传技能、启用中的模型和凭据、已发布智能体及活动应用支持一次确认软删除。权限要求不变，历史身份、不可变修订、发布快照、聊天记录和账单保留。
- 引用校验区分当前与历史。非删除的智能体草稿及当前发布、活动工作成员、有效 Key、当前知识配置和在途运行/准备/图谱任务受到保护；已删除资源、移除成员、旧发布、终态 Run、旧金额费率、撤销或过期授权不再永久阻挡删除。
- 页面列出引用的名称、状态和处理路径，草稿与已发布版本分别展示。其他用户的私有引用隐藏名称、标识和路径；无权查看的资源只显示通用说明。链接限制为站内路径。
- 同 slug 的技能预检区分安装、更新、恢复、已安装。更新保留身份并追加不可变修订；恢复重新启用；相同内容不重复创建。预检目标和版本被固定，确认请求冻结返回值，旧确认重放不会读取成后续新修订。
- 停用应用可以修改名称，删除活动应用同时停用其新调用。应用重新启用前复核有效 Key 的模型；工作重开前复核冻结依赖，并按 Model → Connection → Agent → Task → Skill 锁序接纳和复核任务版本。
