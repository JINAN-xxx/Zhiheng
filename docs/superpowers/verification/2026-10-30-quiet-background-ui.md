# 后台静默观察与存储管理精简

本轮按用户要求整体排查“上传、解析、切片等待时页面反复刷新”，并精简存储管理。改动仅在前端；沿用现有 API、后台 Worker、文件权限、账务和存储策略，没有新增任务系统、SDK 或数据库迁移。

## 原因与行为变化

知识文档原来每 1.2 秒调用完整详情读取，重新取库、文档、文件夹和任务列表，并进入表格 loading。非空表反复出现遮罩；空表或筛选空时还会重建表格。并非浏览器调用了 location.reload，但视觉和操作体验接近持续刷新。

现在只观察当前任务，初次加载和显式刷新与后台读取分开。任务终态后静默同步文档、目录和库摘要；摘要单独失败时只重试摘要。保留表格、输入、焦点、文本选择、滚动、预览、目录及历史展开状态。任务历史默认收起，当前任务显示紧凑进度。

上传取得服务端 202 后即可切换页面，处理继续；二进制尚未上传完、没有服务端身份时阻止路由离开，避免丢失未接纳文件。未知接纳继续沿用原请求标识和恢复流程，不通过轮询重复提交任务。

图谱、检索准备和存储对账的观察统一使用可取消的可见性等待：隐藏标签暂停读取，返回立即观察，离页清除本地计时器与请求，服务端任务继续。瞬时错误保留画面并退避，权限或来源的权威拒绝清除受保护数据。观察错误与取消等写错误独立，不因读恢复误清未知写结果。

图谱初次 config/subgraph/labels 各读取一次，等价数据复用对象，避免重绘画布和重置配置输入。服务端过滤的历史从列表移除；版本和终态防倒退，过期观察、恢复与跨库响应不能覆盖新状态。

存储管理默认显示简洁文件列表、文件名与常用类型搜索、文件/回收站切换、当前查询的数量及空间。高级筛选、详细统计、保留策略、提醒、对账以及授权/转移/引用/审计仍保留，按需展开。选中后才显示批量操作；刷新按文件身份保留有效选择，切换筛选/分页才重置。权限、CAS、引用、派生文件和永久清理保护保持原规则。

- 知识库新增 13 项 Chromium 回归及 29 项去重旧流程/上传幂等回归通过；终态摘要失败、权限变化和过期恢复补充 5 项真实 composable Node 红绿及 3 项浏览器聚焦复验。
- 图谱 28 项自身浏览器用例通过，最终 4 项关键浏览器和 31 项相关 Node 小集通过；存储 22 项完整浏览器、11 项 AI 权限和手机操作列 3 项聚焦复验通过。友好类型、自定义 MIME、选择及原权限另外 9 项必要定向回归通过。
- 独立只读复审发现并复核关闭：观察恢复误清取消写错误（含相同网关文案）、终态摘要失败不再同步、旧恢复隐藏新结果、来源 409 的保护清理、存储撤权后的旧数据和无限重试。

上述小集存在重叠，不累计为唯一用例总数。关键行为均有失败证据和对应绿灯。并发开发时曾捕获 Chromium `ERR_NETWORK_CHANGED` 和 Vite 热更新导致的初载中断，保留了诊断，稳定源码后复验通过，未放宽权限或业务断言。

请求量实测：同样等待 3.5 秒，文档/文件夹从各 3 次降为各 1 次，期间仅 2 次当前任务读取；含完成全过程，文档/文件夹各 2 次（初次与终态各一次）。

## 真实上传与索引链路

使用独立 API、Worker、PostgreSQL、Redis、Milvus、etcd 和对象存储，全部复用缓存镜像。浏览器所有业务请求转发真实测试 API，没有伪造业务响应；向量请求只访问本地合成供应商，不调用正常模型服务。

5 项真实流程检查全部通过：实际上传取得 202，Outbox/Worker 原生解析与向量索引；供应商受控等待时没有重拉文档/文件夹，也没有表格加载遮罩、DOM/焦点/选择丢失；完成后各同步一次并保留搜索条件；再次上传后切到模型页，没有发送取消请求，返回时三个文档均已完成索引。另完成实际存储刷新保留选择、回收与恢复 CAS、高级入口及手机无页面横向溢出，0 页面脚本错误。

默认类型筛选使用“文本、PDF、Word、Excel”等友好名称，文件摘要显示大小与扩展名；原始 MIME 保留在详情和高级自定义筛选。额外真实 API 浏览器复查验证“文本”精确发送 `mime=text/plain`，自定义值原样传递并显示“自定义类型”，没有业务写入。首次辅助脚本误点 Ant Select 内部透明输入，改用实际选择器后通过，产品交互与断言未放宽。

## 运行与边界

正常入口仍为 19080 源码模式。本轮不修改后台或数据库，不重启模型、Worker 或数据服务，不修改正常文档、保留规则、角色、价格、用户积分或计费开关。服务端已接纳任务的后台能力本来就存在，本次解决前端观察和日常管理的干扰。
