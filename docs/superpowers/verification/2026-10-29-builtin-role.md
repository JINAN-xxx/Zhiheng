# 内置角色与后台入口调整

用户指出角色列表为空，经核对原正常实例 `admin.is_admin=true`、角色记录 0 条、账号角色关联 0 条。原账号实际拥有超级管理员权限，缺口是默认角色及其真实关联未初始化。

## 行为

- `0011_builtin_admin_role` 添加唯一的内置角色标记，初始化“超级管理员”并关联已有管理员，保留普通角色及原有关联；遇到相同角色编码时选择备用编码，不改写用户已有角色。
- CLI 与后台创建管理员、提升或取消超级管理员身份时同步系统角色关联。系统管理员权限继续由原有身份决定；内置角色不通过普通权限勾选授予，普通账号不能手动分配系统角色。
- 角色页显示“系统内置”“全部管理权限”和真实成员数，可只读查看，不能编辑、停用或删除。用户页与账号菜单统一显示“超级管理员”。
- 根据用户补充要求，主侧栏移除“平台管理 → 后台管理”，只在左下角账号菜单按权限提供入口。进入后台后保留管理功能导航。
