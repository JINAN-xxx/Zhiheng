# 内置智能体验收记录

日期：2026-10-23。分支：`refactor/ai-core-modularization`。本组沿用原智能体界面，将草稿、发布、预览和 API 调用接到新平台，不恢复旧插件运行机制。

## 已交付

- 智能体列表、配置、新建应用、模型/技能选择、完整配置保存、CAS 冲突处理、发布/重新发布、取消发布与删除。草稿版本和发布序号独立；公开调用读取不可变发布配置和技能全文快照。
- 原试聊抽屉接纳持久 Run，通过共享快照/SSE 查看；推理与正文分别保存。静默供应商可以停止，停止确认前保持请求占用；丢失接纳响应时复用原请求标识，已接纳后只恢复观察。
- `/v1/agents/{id}/chat/completions` 支持真实 JSON 和 OpenAI SSE，Key 绑定已发布应用与模型。修改草稿不改变公开应用/参数，重新发布才切换。错应用、未发布与不存在均拒绝，不调用供应商。
- 调用走同一 worker/LangChain/Token 预留与费用账本；Run 调用者和计费资源 owner 分开，管理员代操作不会借用管理员预算。公开模型需先配置费率，缺失时拒绝，不默认免费。
- 模型输出上限恢复为1..131072并受所选模型限制。普通聊天保存推理历史，历史推理不再送回模型。SSE 在有边界的事件缓冲内支持2MiB模型正文/推理的 JSON 转义。
- Key 创建/撤销互斥、一次明文仅留弹窗内；关闭、换对象、注销和组件销毁清理请求所有权与确认框，拒绝晚到响应。
