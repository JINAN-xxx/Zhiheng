# 后台管理恢复验收

日期：2026-10-28。后台按新平台 identity/operations 边界实现，沿用当前控制台 UI，依赖版本保持 LangChain 1.4.7、LightRAG 1.5.7 和 Python 3.12。

## 功能与入口

- 一级“后台管理”和头像菜单进入 `/admin`；后台有用户、角色权限、部门、岗位、菜单、字典、参数、公告、登录日志、操作日志、在线会话、系统状态 12 个页面。
- 角色权限实际约束后端接口，启停与撤权对原会话后续请求生效；用户管理保护本人和最后一个管理员。删除保留历史业务归属，密码重置及账号停用撤销会话。
- 部门防环与占用保护，岗位/角色引用保护，固定后台页面的菜单名称、顺序、显示配置；隐藏不移除服务端权限校验。既有停用关联可保留，新增关联仍须有效。
- 字典类型/数据、参数、公告均持久化并使用版本检查。当前参数是已接通的公告开关，发布公告实际展示于平台通知面板，正文按纯文本处理。
- 登录及操作摘要入库，在线会话使用独立 UUID 撤销，不公开令牌或摘要；监控读取真实 PostgreSQL、Redis、Worker 和进程/文件系统状态。
