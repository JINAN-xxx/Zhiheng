# 知识库主向量索引与检索验收

日期：2026-10-27。分支：`refactor/ai-core-modularization`。正常实例已运行 `0007_knowledge`；本组保留原知识库、文档和检索界面，AI 能力内置于核心。

## 已交付行为

- 库、文件夹、文档、原文预览、上传、重新切片、全库重建、递归删除、索引进度与明确取消。原文使用受管文件，不接受任意路径；上传恢复保留原请求身份，已知暂存上传可显式清理。
- 原生解析和分块、真实受治理 Embedding、Milvus 2.6.25 / pymilvus 2.6.17。完整不可变 generation 使用独立 namespace，经写入、索引、加载和校验后切换 manifest；部分导入显式标记 partial，重建失败保留旧指针，binding 改变须显式重建。
- 库 ACL 与原文件 ACL 取交集；共享库不自动公开原文。管理员代操作按原资源所有者选择来源。检索 pin 阻止在用 generation 被 GC；清理只处理登记的精确 namespace。
- Chat、智能体预览、公开智能体 API、Work 的持久知识准备与来源。资料和附件分别保存，资料只进入本轮 user 数据消息；固定引用规则、系统提示、技能、多轮历史和图片保留。
- 公开 Key 同时授权主模型及检索向量模型，两类调用进入同 Key 配额与用量。稳定请求键、同 Key polling URL、原结果重放和真实主 Run 取消已接通；模型停用不会阻断有权读取的原结果，真实授权撤销仍拒绝读取及取消响应。
- 每个协调 tick 归还 worker 槽位，付费子步骤使用标准 Run、outbox 和账本。RPC 使用共同绝对期限，取消与租约过期先 drain 再关闭连接；旧执行不能发布，GC tombstone 会按精确身份复查迟到 namespace。
