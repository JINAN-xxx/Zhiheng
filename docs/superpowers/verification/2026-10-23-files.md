# 受管文件、原生解析与聊天附件验收

日期：2026-10-23。分支：`refactor/ai-core-modularization`。文件与 AI 能力均为内置模块，保留原文件管理和聊天界面。

## 已实现

- 受管字节保存在新 `files-data` 卷，API 与 worker 共享，UID/GID 为 `10001:10001`。StoragePort 只使用不透明键；上传上限20MiB，实际校验 MIME、大小与 SHA，下载经过 Cookie 身份及文件权限校验，支持单 Range、ETag 和实际传输字节审计。
- owner/admin 管理、上传人开关、平台内公开、显式用户 allow/deny/有效期。公开仍须登录；deny 覆盖公开/上传人/allow，owner/admin 不受覆盖。派生解析产物继承原文件权限与生命周期。
- 原列表/筛选/统计、详情编辑、ACL/归属转移、业务引用、分页审计、回收/恢复/清理、资源保留策略、到期提醒和存储对账。没有未实现的角色/部门选择器；768px 等平板宽度的抽屉控制保持可见，暗色提示与输入占位可读。
- 普通删除仅处理 active 文件；source 或任一派生产物存在业务引用时拒绝，查询不受列表100条展示限制。重复删除不重置回收期限；purging/purged 保持原有终态保护。到期处置只解除已过期引用，永久/未到期引用继续阻止；已在回收站的到期文件保持原删除时间和保留期限。
- 提醒公开投影为 expired/expiring，按当前有效期限返回；取消或修改期限后旧提醒失效。维护扫描每批有界并持久游标；手动/周期操作互斥。每次事务验证同一数据库连接的执行身份，失联扫描不能覆盖后来隔离状态或发布成功游标。
- 原生 PDF/DOCX/XLSX/TXT/MD/CSV/JSON/HTML 解析，共用 knowledge 解析端口。实际解析在有内存、CPU、超时、ZIP 展开、页数、单元格和输出上限的子进程内执行；取消会终止并等待子进程。空结果、扫描 PDF 需 OCR、非法文档明确失败；没有把原生解析宣称为 OCR。
- 聊天恢复原附件队列、移除、重传、图片预览及历史下载。每轮最多10图、5文档；文档每件40000字符、总60000字符，模型请求中历史与本轮安全图片总量16MiB。图片经像素/帧限制和 JPEG 归一后以真实 LangChain image_url 发送，模型必须启用 vision。未知接纳结果保留原请求键和附件顺序。
- 原会话重命名、归档/取消归档、删除。当前状态、版本冲突、结果未知及迟到响应受控；归档或状态待核对时不能继续发送或重传附件。删除会话保留运行/用量事实，同事务解除其历史运行文件引用。
