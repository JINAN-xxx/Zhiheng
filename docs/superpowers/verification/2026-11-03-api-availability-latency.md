## 可用性覆盖与发现

[逐接口 CSV](2026-11-03-api-endpoints.csv) 列出全部 269 个操作的成功证据及延迟。`normal_local_*` 为正常实例真实 HTTP；`private_tcp_*` 为隔离实例真实 HTTP；`controlled_asgi_*` 为既有回归的进程内耗时，包含故障模拟与不同输入规模，不用于推断正常网络延迟。小样本端点的分位数仅作本次记录，不作为 SLA。私有 TCP 链路覆盖 91 个唯一接口操作，另将流式与非流式分开统计。

发现以下问题，未在本次审计中修改实现或旧断言：

1. **25 个后台管理接口文档路径缺少 `/api/admin` 前缀。** 例如文档为 `/users`，真实接口为 `/api/admin/users`。实际接口可用，按错误文档路径调用会失败。
2. **现有知识库的图谱尚未构建。** 正常实例的 labels、subgraph 返回 `409 graph_not_ready`。隔离环境真实构建后对应接口成功；图谱/Milvus 专项 58 项全部通过。
3. **7 项打包单元测试失败。** 测试样本的迁移清单只列至 0016，校验器已要求 0017；本次未重新构建包，不能据此判断真实 wheel 缺文件。
4. **3 项旧聊天行为断言不一致。** 超大系统提示词当前返回 `422 context_input_too_long`，旧用例期待 400；归档会话追加消息当前返回 `409 conversation_archived`，旧用例期待 202；10 张大图被当前 8192 输入预算拒绝，旧用例期待接受。
5. **1 项摘要用例存在未确定原因的首次失败。** 首次未创建期望的自动摘要任务；同源码、同用例独立复测通过。保留原失败，不认定已修复，也没有证据将原因归为超时。

唯一回归用例共 1148 项：首次 1136 通过、11 失败、1 跳过；跳过的 Nginx 用例已用本机缓存镜像补测通过，因此确认状态为 **1137 通过、11 项原失败保留**。摘要独立复测不覆盖首次失败。269 个接口出现成功场景不等于所有业务边界均无缺陷。
