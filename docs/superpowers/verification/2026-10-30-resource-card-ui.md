# 资源卡片统一与验收

本轮按用户确认的紧凑设计调整模型、智能体和工作记录条目。共享 `ResourceCard` 只负责标题、状态、内容、辅助信息和操作插槽；`ResourceCardGrid` 根据实际容器宽度切换三、二、一列，各业务模块继续拥有数据、权限、请求和生命周期。

## 已实现行为

模型默认隐藏整行 UUID，标题旁可复制，点击名称可查看只读详情与完整 ID。只有对话模型显示最大输出，向量与重排序显示用途。底部保留有权读取的连接名称，移除重复启用状态；测试作为常用操作，编辑、费率、启停、发布与删除保留在更多菜单。停用模型或已知停用连接的测试禁用，卡片、桌面列表和手机操作菜单一致。没有连接读取权限的测试用户不被未知连接状态误拦截，连接详情也不向其显示。

智能体名称进入原完整配置页，保留全部模型、提示词、技能、知识库、参数和发布配置。卡片保留说明、技能/知识库数量、真实发布/草稿版本及未发布更改，试聊常驻；配置、已发布 API 和复制 ID 从更多菜单进入。原发布、取消发布和删除保护继续由完整配置页承接，配置页增加只读完整 ID。

工作记录仍在原 620px 居中历史弹窗内，使用紧凑单列卡片，显示目标摘要、运行状态和最近更新时间。原搜索、筛选、归档、分页、所有者权限、当前运行保护与打开后关闭弹窗的行为保留。目标详情增加只读工作 ID；工作成员、消息区和执行流程没有改版。手机端工作记录不横向溢出，模型沿用原紧凑列表，智能体为单列。

复制 ID 的异步反馈受当前页面与操作作用域约束。连续复制、切换详情、搜索、打开配置/试聊或离页后，旧复制失败不能覆盖新的界面。
