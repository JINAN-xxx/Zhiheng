# 个人资料与界面一致性验收

本轮补齐左下角账号菜单的“个人资料”，调整对话输入区，并按当前白色界面核对主页面与配置浮层。

## 交付行为

- “个人资料”进入 `/profile`，提供显示名称、邮箱、联系电话编辑及本人密码修改；账号、角色、部门、岗位与创建时间只读，未知时间使用 `—`。界面复用当前 Workspace 与 Ant 组件，桌面分栏、手机单列，页面可滚动到安全操作。
- 本人资料 API 固定取登录身份，拒绝角色/权限等额外字段，保存使用版本检查；409 保留草稿，显式重新加载后才能继续。密码需验证原密码，成功撤销全部会话并重新登录；错误原密码返回 400，保持有效登录。成功提示使用绿色，与登录错误区分。
- 对话模型选择位于输入框下方的操作栏；手机将附件工具与模型/发送分为两行。“文本与图片/文本对话”标签已去除，状态反馈仍保留，历史/设置、技能、知识、附件、发送/停止行为继续使用原状态与事件。
- 凭据名称原先误用 `code`，现使用与模型名称一致的系统字体与字重，移动状态标签宽度也已修正。共享表格主题改用项目所装 Ant Design Vue 4 的有效 token，开发接入、存储、后台等表头统一为 13px、500 字重和浅色底色；代码、URL、标识符的等宽语义保留。
