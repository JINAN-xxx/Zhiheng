# 内置技能模块实现计划

> **面向 AI 代理的工作者：** 使用 `subagent-driven-development`，先规格审查、再质量审查。每步记录真实 red→green，不修改 `legacy/` 的原有优化。

**目标：** 恢复原技能管理页面与两阶段安装，提供智能体后续可冻结使用的提示词包。

**架构：** `modules/skills` 拥有包解析、草稿、技能与不可变内容；通过 `public.py` 暴露选择解析。小型技能包保存于 PostgreSQL BYTEA，避免 API/worker 的本地磁盘差异；包中附属文件随原包保存，模型使用主文件全文。状态与内容版本分开，取消插件生命周期。

**技术栈：** FastAPI、SQLAlchemy、PostgreSQL、PyYAML、Vue 3、TypeScript、Ant Design Vue。

## 契约与范围

- 技能是平台共享目录：登录用户可列出、查看和选用；管理员可安装、启停和删除。上传草稿绑定上传人，任何账号都不能确认他人的草稿。
- 管理 API 使用 `/api/skills`：GET 集合分页 `{items,total,page,page_size}`，可按 `search`、`status` 查询；GET `/available`、`/{id}`、`/{id}/content`；POST `/import/prepare?filename=...` 上传原始 `application/octet-stream`；POST `/import/{draft_id}/confirm`；PATCH `/{id}/status`；DELETE `/{id}`。
- DTO 使用 snake_case。技能字段 `id,slug,name,description,package_version,version,status,source,revision_id,content_hash,file_count,total_bytes,created_at,updated_at`；内容返回 `content`；准备结果含 `draft_id,expires_at` 与解析后的包摘要。
- 状态请求 `{status:'enabled'|'disabled',expected_version:positive int}`。空命令只接收空 JSON 或无 body；未知字段拒绝。删除要求停用，builtin 不可删除；保留历史内容。后续智能体绑定时通过模块公开接口增加引用保护。
- 上传限制 10 MiB；解压总量 30 MiB、200 个普通文件；主文件 128 KiB；主文件 UTF-8，YAML front matter 字段沿用原 `name/display_name/description/version`。禁止路径穿越、绝对路径、反斜杠、冒号、大小写重复、链接、特殊文件、加密包及超过实际读取限制的压缩包。
- 草稿有效期 3600 秒；确认时核对归属、有效期与原包/文件树摘要，同一草稿重复确认返回已安装对象，同一 slug 不覆盖。确认的 Skill 与 Revision、包原始字节同事务写入。过期草稿由受监督 worker 维护任务分批清理。
- 选择解析保留顺序，最多 5 项、主文件合计 32 KiB，拒绝重复、停用、删除和缺失项；返回不可变 revision ID、内容摘要及主文件全文。附属文件不执行，不增加脚本运行功能。
- 两个原 builtin（deep-research、document-summary）由显式版本化迁移种入，内容按当前 legacy 文件冻结；API 和 worker 启动不写 schema，不通过启动 hooks 覆盖内容。
- 上传例外只放行该精确路径的 octet-stream，并保留来源检查与大小限制；其他管理写入继续要求 JSON。

```python
prepared = await admin.post('/api/skills/import/prepare?filename=SKILL.md', content=skill_md, headers={'Content-Type': 'application/octet-stream'})
assert prepared.status_code == 201
installed = await admin.post(f"/api/skills/import/{prepared.json()['draft_id']}/confirm", json={})

assert installed.json()['status'] == 'enabled'

```
