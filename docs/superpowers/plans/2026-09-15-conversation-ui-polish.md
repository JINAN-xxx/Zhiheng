# 智能对话视觉优化计划

**目标：** 沿用单一智能对话入口和中心聊天 / 工作切换，统一空态、输入、智能体选择与消息的视觉层次。

**架构：** 调整现有 Vue 组件的展示结构和局部样式，沿用当前主题变量、图标和交互事件。空白聊天将输入框移到欢迎区下方，已有对话继续使用底部输入；工作目标和成员/执行者收进统一输入卡片。

**技术栈：** Vue 3、Ant Design Vue、现有主题变量、Vite、Playwright。

- [x] 优化 `WorkspaceModeSwitch.vue` 和 `ChatEmptyState.vue`：紧凑分段按钮、轻量图标、标题和说明层次。
- [x] 优化聊天 `index.vue`：空态中心输入、统一卡片宽度与圆角、轻量工具栏和消息气泡；保留原有聊天事件与表单绑定。
- [x] 优化 `WorkEmptyState.vue`：目标输入、已选成员、执行者与开始按钮组成单张卡片，手机宽度内自然排列。
- [x] 优化 `WorkAgentPicker.vue`、`SkillPicker.vue`：可滚动列表、清楚的选中态、名称/描述/版本分层及适配窄屏。
- [x] 优化 `WorkTaskPage.vue`、`WorkMemberBar.vue`、`WorkMessageTimeline.vue`：任务标题、成员标签、内容和底部输入形成统一阅读宽度。
- [x] 运行现有 31 组前端回归及聊天/工作、权限、任务操作浏览器验收；检查桌面、手机与深色主题截图。
- [x] 构建 Docker 模式前端并更新 `12580`，保留旧静态产物，记录发布信息；不变更后端与数据库。
- [x] 补充 `AppMain.vue` 对话页安全区处理及多成员区域滚动，修复 320px、10 成员和 7 行输入时祖先容器裁切按钮的问题。

视觉验收重点：欢迎区和输入区连贯；两种模式同属一个页面体系；单入口保留；长标题、窄屏和已选多个智能体时发送/停止操作可见。
