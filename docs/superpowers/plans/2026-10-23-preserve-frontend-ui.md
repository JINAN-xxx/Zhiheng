## 范围与所有权

- `legacy/frontend/` 是界面基准，原有 40 份未提交前端优化逐项保持原样。复制必要品牌资源、视觉 token、布局和纯展示组件到正式前端，补齐明确的导入、类型和新契约。
- 当前接通范围为登录、工作台布局、聊天、模型/凭据和用量。知识库、Agent、Work 等原页面继续保留，后端能力补齐后逐域接通。
- `frontend/src/app/` 拥有工作台外壳；各业务模块拥有自身状态与接口；保留当前取消、恢复、请求隔离及严格 DTO 边界。
- `frontend/src/shared/` 复用原视觉 token、字体、间距、表格和状态表达。页面外观以原界面为准，不引入新的产品视觉或图标品牌。
- `frontend/tests/` 和 `backend/tests/core/e2e/browser_check.py` 验证真正的接口与浏览器行为。测试选择器可随原文案和控件恢复而更新，业务断言继续保留。
- 当前没有真实支撑的旧功能不得伪成功；其来源和未接通范围明确记录。禁止为复用前端而重新依赖旧后端、LiteLLM 或插件生命周期。
