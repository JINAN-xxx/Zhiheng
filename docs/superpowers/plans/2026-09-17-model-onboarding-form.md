# 模型接入单页表单

用户已选择单页表单：先选模型类型、填写模型名称，再配置连接，最后测试并接入。继续自动生成别名，不要求手填技术标识；桌面样式沿用智能体扩展的公共主题。

设计：右侧抽屉保留，移除三阶段跳转。顶部模型类型（对话、向量、重排序）、上游模型名称和展示名称；下方服务商、已有连接或新凭据；高级设置只包含超时、重试和类型专属默认参数。底部唯一操作区为取消、测试连接、接入模型，并就地显示测试及接入进度。模型代码和别名内部生成，并附加随机后缀，支持同名上游模型通过不同连接分别接入。

连接测试可以使用未保存凭据，并携带明确模型类型。仅最终接入时依次保存凭据、部署、目录、绑定和发布；重试复用已完成资源。保存开始后锁定连接字段，防止混用已保存资源和新配置。测试中锁定表单；测试完成后任何连接相关修改都会使结果失效。请求代际保护关闭/重开抽屉；不在浏览器持久化密钥，凭据读取沿用现有大小、类型及脱敏校验。
