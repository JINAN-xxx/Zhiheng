# AI 平台管理权限与角色编码

用户确认：基础对话与本人智能体、知识库、开发应用等能力保留；平台级管理能力按角色授权。新角色编码由后端生成，旧编码稳定且编辑只读。

## 权限约定

| 代码 | 能力 |
| --- | --- |
| `ai:models:read` | 查看完整模型与服务连接配置，不返回密钥原文 |
| `ai:models:write` | 创建/编辑/启停/发布/删除模型与连接，同时可读取配置 |
| `ai:models:test` | 发起受原配额与用量治理的连接测试 |
| `ai:rates:read` | 查看模型费率 |
| `ai:rates:write` | 配置费率，同时可读取费率 |
| `ai:skills:write` | 导入、启停与删除平台共享技能 |
| `ai:storage:read` | 查看存储保留策略、对账与维护记录 |
| `ai:storage:write` | 修改策略与执行存储维护，同时可读取治理记录 |

只读接口显式接受对应 read/write，不改变原 `system:*` 权限精确匹配规则。超级管理员继续使用现有身份标志。本人智能体、知识库、应用与文件的所有权/ACL不由上述权限扩大；文件跨所有者创建、内容访问及权限/所有权修改规则不变。

角色目录合并系统与 AI 权限，支持授予目录全部项目；授予仍受调用者持有权限的子集约束，停用角色或撤销授权后后端立即拒绝新请求。AI 权限本身不提供后台系统管理入口。

## 实现边界

- 主代理：shared Principal 任一权限判断及测试、计划、隔离测试基础设施、整体联调/审查。
- 身份后端：权限目录/有效权限集合、角色请求上限、自动编码默认值、相关契约/角色授权测试。保留显式 API 编码兼容，普通创建表单不提交编码。
- AI 后端：模型服务/路由、测试接纳、技能、存储策略/治理接口与作业；保留其他所有权/ACL分支，完成授权/越权/撤销测试。
- 前端：公开权限判断、角色新建/权限分组、模型/费率、共享技能、存储入口和读写界面，含普通账号与已授权角色的浏览器验证。
