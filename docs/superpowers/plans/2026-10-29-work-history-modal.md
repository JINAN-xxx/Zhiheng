# 工作空间历史弹窗

用户要求工作空间采用与对话体验一致的优化：工作记录居中弹窗，查找/切换后关闭，不展开常驻左栏或挤压主区。新建工作常驻工具栏。

- [x] `WorkHistoryDialog` 复用 `WorkNavigation` / `RecentWorkTasks`，保留最近/归档、搜索、状态筛选、分页、重命名和删除及原有权限/运行锁。
- [x] 移除 `WorkView` 历史列、手机侧栏和遮罩；工具栏工作记录/新建工作在桌面与手机均可使用。
- [x] 主区按剩余高度布局，打开弹窗不改变任务区位置/尺寸；关闭不重建目标/成员/消息组件，草稿和运行观察保留。
- [x] 既有工作回归改为显式弹窗操作；新用例覆盖目标和消息草稿、选择后关闭、手机、长列表滚动及尺寸不变。
- [x] 前端核心、类型、规范、适用浏览器及正常实例只读核对；不打包、不改后台、不调用收费模型，保护原 57 份优化。
