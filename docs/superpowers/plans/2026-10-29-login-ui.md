# 登录页改版实现计划

**目标：** 将登录页改为用户选定的左侧品牌图形、右侧登录表单，保持平台白色风格。

**文件与职责：**

- `frontend/src/shared/components/AuthShell.vue`：品牌、几何图形、两列与手机布局，移除未使用的旧布局选项。
- `frontend/src/modules/identity/views/LoginView.vue`：带可见标签的表单、按钮与账号提示，保留认证调用。
- `frontend/tests/browser/ui_regressions.py`：更新旧“记住密码”断言，继续验证既有登录链路。

- [x] 检查页面、认证接口及现有测试，保存改版前截图和源码，核对原 57 份优化保护清单。
- [x] 改造左右布局和品牌图形，移除外围卡片、无效控件及英文页脚。
- [x] 整理表单间距与可见标签，保持提交、回车、失败重试和取消行为。
- [x] 运行定向登录回归、类型与规范检查；浏览器核对 1440×900、1024×768、390×844、320×568 和横屏短窗口。
- [x] 正常实例实际登录，只读核对跳转；保存截图和验收结果，确认原优化未变，提交当前改版。

基础命令：`npm run typecheck`、`npm run lint:core`、`npm run format:check`。浏览器使用当前 `19080` 源码实例和已安装 Playwright，按 `PlatformUIRegressions` 中 4 项登录用例及知识上传的重新登录用例定向运行。

结果见[登录页验收](../verification/2026-10-29-login-ui.md)。
