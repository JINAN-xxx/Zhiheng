# 内置智能体实现计划

> **面向 AI 代理的工作者：** 使用 `subagent-driven-development`，先规格、再质量审查；保留原界面和 legacy 未提交优化。

**目标：** 恢复智能体配置、独立发布版本、草稿试聊和应用 Key 对外调用，为后续 Work 提供发布快照。

**架构：** `modules/agents` 拥有草稿和不可变发布版本，`application/agent_runs.py` 编排模型、技能、应用授权与持久运行。模型推理复用统一 executor/outbox/账本，不另起 SDK、HTTP 内后台任务或插件生命周期。

**技术栈：** FastAPI、SQLAlchemy/PostgreSQL、ARQ、LangChain 1.4.7、Vue 3/TypeScript、Ant Design Vue。

## 功能契约

- 普通账号管理自己的智能体，管理员可代管理；所有模型/应用/技能/知识访问明确使用资源原 owner 的身份，不借管理员权限绕过业务绑定。
- 字段为 `name,description,model_id,system_prompt,welcome_message,skill_slugs,knowledge_base_ids,application_id,temperature,max_tokens`；限制沿用原审计：名称100、说明500、系统32000、欢迎语2000、技能最多5/总32KiB、知识库最多20、temperature有限0..2、max_tokens整数1..131072且不超过模型输出上限。欢迎语只在界面展示，不进入模型消息。
- 草稿允许不绑定应用，发布要求原 owner 的有效应用和可用 chat 模型。更新/发布/取消发布使用 `expected_version`，旧版本409；编辑不改变已发布快照。发布保存不可变版本和技能 revision/hash；取消发布只撤回当前指针，历史版本保留；删除要求先取消发布。
- 新公开路由 `/api/agents`：GET 分页/search/status、POST 创建、GET/PATCH/DELETE `/{id}`、POST `/{id}/publish|unpublish`、POST `/{id}/preview`；DTO snake_case 严格校验；preview 返回202 RunSnapshot，通过既有 Run 快照/SSE/取消接口观察。
- 试聊请求只含 `messages`（1..96条 user/assistant 文本、最后user、合计64KiB）、`client_request_id`，禁止调用者覆盖绑定。使用已保存草稿；系统提示词→技能全文→知识引用规则→历史/当前问题的顺序冻结入本次 payload，记录技能摘要与配置版本。
- `/v1/agents/{id}/chat/completions` 只允许 Bearer 绑定应用访问当前发布版本，先验证 Key/应用/模型授权及配额，再准备上下文；复用现有公开 JSON/SSE 传输与费用账本。模型ID和参数从发布配置取得，调用方不能覆盖。取消发布阻止新调用；已接纳请求保留冻结输入。
- 本域预留明确知识上下文边界：非空知识绑定且检索模块不可用时，调用以稳定错误拒绝，不静默转普通聊天。文件/知识库域将向该边界提供真实检索、来源/字节范围和原 owner 校验；最终功能对齐验收覆盖该组合。
- 模型/技能删除保护由 application 用例通过 agents.public 查询草稿与历史版本引用；模型行锁先于写入绑定事实，禁止跨模块 ORM。并发发布、删除与模型禁用/删除不得出现死锁或悬空绑定。
- 模型输出配置同步恢复原1..131072范围，API、ModelBinding、供应商调用、公开上限与前端校验一致；实际调用始终受所选模型限制和 Token 预留约束，不隐式提高配置或配额。
