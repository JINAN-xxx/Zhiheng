# 模型中心界面风格统一

用户指定以“智能体扩展”的现有页面为视觉标准。范围为模型目录（平台模型、凭据管理）、开发接入（列表和详情）、用量记录。业务操作和权限规则沿用现有实现，表格内容保持表格呈现。

## 视觉基准

- 使用现有 WorkspaceToolbar 单行 20px 标题与标准圆形刷新按钮，页面标题对应当前子页面；移除三个页面额外的页眉副标题。
- 页面使用 `--workspace-font-family` 与 `--bg-container`；内容区域采用与智能体/技能页一致的桌面 `20px 24px 28px`、手机 `16px` 留白。
- 表格页筛选条参照技能管理：轻边框、8px 圆角、输入与控件统一高度、紧凑间距、数量信息置右。
- 面板和表格使用轻边框、8px 圆角；标签、正文及次级信息沿用平台主题，不保留模型页自定义字体与胶囊标签样式。
- 开发接入移除重复的“应用列表”面板标题，将搜索与数量放在内容顶部；用量记录统一圆形刷新和筛选区留白。
