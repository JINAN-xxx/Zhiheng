# 最近会话重命名与永久删除设计

## 目标

为智能对话侧栏中的最近会话增加重命名与永久删除能力。删除后不保留归档状态、不提供回收站，也不提供恢复入口。

## 行为

### 重命名

- 会话操作菜单提供“重命名”。
- 点击后打开输入弹窗，默认不回显敏感消息内容，只要求输入新标题。
- 标题去除首尾空白后必须为 1～200 字，不允许控制字符。
- 更新成功后立即修改侧栏标题，并刷新最近会话时间。
- 用户只能修改自己的会话。

### 永久删除

- 会话操作菜单提供红色“删除会话”。
- 删除前明确提示“删除后无法恢复”，用户确认后才请求后端。
- 用户只能删除自己的会话。
- 若会话存在正在等待或运行的模型任务，返回会话忙错误，不执行任何删除。
- 删除顺序为运行记录、消息、会话，并在同一数据库事务中完成。
- 任一步骤失败时回滚全部删除。
- 删除当前会话后跳转到新对话；删除其他会话时保持当前页面。

## 接口

### 修改会话标题

```text
PATCH /ai/chat/session/{session_id}
```

请求：

```json
{
  "title": "新的会话标题"
}
```

成功返回更新后的会话摘要。

### 永久删除会话

```text
DELETE /ai/chat/session/{session_id}
```

成功返回“会话已删除”。该接口替换现有归档语义。

## 组件边界

- `PlatformChatDao`：锁定用户会话、更新标题、按外键顺序删除关联记录。
- `PlatformChatService`：所有权校验、运行状态检查和事务边界。
- `ai_chat_controller`：请求校验、权限依赖和响应契约。
- `platformWorkspace`：最近会话重命名与删除请求。
- `workspace store`：更新或移除本地会话列表。
- `RecentSessions`：展示操作菜单并发出语义化事件。
- `PlatformSidebar`：处理输入弹窗、删除确认和当前会话跳转。

## 错误处理

- 会话不存在或不属于当前用户：返回会话不存在。
- 标题为空、超长或包含控制字符：返回请求校验错误。
- 会话有运行中任务：返回会话忙错误。
- 数据库删除失败：回滚并保持前端列表不变。
- 前端请求失败：显示后端中文错误，不提前移除或修改列表。

## 验收

1. 重命名后刷新页面，标题仍保持更新值。
2. 删除后刷新页面，会话、消息和运行记录均不存在。
3. 删除当前会话后进入空白新对话。
4. 删除其他会话不改变当前会话。
5. 不能重命名或删除其他用户会话。
6. 运行中的会话不能删除。
7. 前后端测试、生产构建和真实浏览器验收通过。
