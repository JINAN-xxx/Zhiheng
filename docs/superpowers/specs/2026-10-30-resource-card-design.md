# 资源卡片统一设计稿

用户明确本次范围是截图中的模型资源卡片，以及智能体、工作界面对应模块的视觉一致性。页面导航、工作入口、业务流程和配置字段沿用当前设计；本稿不重做整个平台外壳，也不把工作执行页改成普通聊天。

状态：设计预览，尚未替换业务卡片。

## 预览

入口：`http://127.0.0.1:19080/design-previews/resource-cards-20261030/index.html`。

文件位于 `frontend/design-previews/resource-cards-20261030/`，使用独立 HTML/CSS/JS，不被业务应用导入。可切换模型、智能体、工作卡片，以及紧凑/舒展密度；包含搜索、更多菜单、详情和示例 ID 复制。所有数据均为示例，不连接业务 API。

推荐紧凑模式：宽屏三列，较窄容器两列，手机一列。舒展模式使用两列。密度仅用于比较卡片尺寸，不构成修改当前页面入口的提议。

## 统一结构

卡片按“图标、名称、状态 → 核心内容 → 常用操作”编排，统一白底、细边框、10px 圆角和系统字体。名称 16px，正文约 13px，辅助信息 12px；状态采用一致语义。卡片头部、内容区和底部操作位置对齐，长标题省略并保留完整提示，手机保留可用操作宽度。

默认去掉整行 UUID，标题旁保留复制图标，完整 ID 可在详情中查看。底部不重复显示“已启用”。每张卡片只突出一个常用操作，其他操作进入相同位置的更多菜单。

| 资源 | 主要内容 | 底部辅助信息 | 常用操作 |
| --- | --- | --- | --- |
| 对话模型 | 名称、启停/发布状态、上游模型、输出上限 | 可授权读取的连接名称 | 测试 |
| 向量/重排序模型 | 名称、状态、上游模型和适用用途；不展示不适用的“最大输出” | 可授权读取的连接名称 | 测试 |
| 智能体 | 名称、发布状态、两行说明、知识库/技能数量及未发布更改提示 | 发布版本或草稿版本 | 试聊 |
| 工作记录 | 名称、任务状态、两行目标、正在执行或等待指令 | 最近更新时间 | 打开工作/查看记录 |

模型测试在停用时不可用，启用操作仍位于更多菜单。已发布和草稿智能体保持现有试聊能力；API 接入只在对应发布状态提供。工作样例基于现有 TaskSummary 字段，仅表达资源卡片的样式，不新增一个任务管理入口。

## 能力和数据边界

- 模型的编辑、费率、测试、复制 ID、启停和删除入口保留。智能体的完整配置、发布/取消发布、API 和删除入口保留。工作原有查看目标、执行、完成、重开、归档和删除能力保留。
- 落地时沿用当前权限及有效依赖保护；管理权限不足时不展示对应管理操作，不能为统一样式放宽授权。
- ModelInfo 当前没有更新时间和向量维度字段，本设计不要求显示这些未提供的数据。Agent 的发布版本取 publishedVersion，草稿版本取 version，未发布修改沿用现有判断；不以新增时间字段或额外逐卡请求作为前提。
- 连接名称仅在有权读取时显示；不暴露凭据、密钥或其他用户私有资源。资源名称、角色及状态仍使用真实数据，本预览的样例配置不代表模型供应商规格。
- 正式实现宜抽取小型共享卡片骨架，通过内容、辅助信息和操作插槽保留业务差异；不让共享组件直接负责模型/智能体/工作的接口或状态管理。

## 预览核对

真实 Chromium 已验证三类各 4 张卡片、两种密度、停用模型测试不可用、模型 ID 详情/复制、更多菜单、搜索空态和手机无横向溢出。只有对话模型显示输出上限，0 业务 API 请求、0 脚本错误。JavaScript 语法检查、Prettier 和差异空白检查通过。
