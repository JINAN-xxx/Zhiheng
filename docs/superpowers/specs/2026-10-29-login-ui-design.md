# 登录页设计

用户选择左右布局，左侧品牌图形、右侧登录。沿用平台的连续白色底色、系统字体和蓝紫主色，以留白组织区域，不设置分割底色、外围登录卡片或大幅英文标语。

- 左上角保留现有智衡标识。桌面左侧为同一标识搭配静态几何线条，辅以“对话 · 智能体 · 知识库”；图形仅装饰，不加载图片、字体或第三方资源。
- 右侧表单宽度约 380px，仅保留“登录”标题，不设置副标题和账号分配提示。账号和密码使用可见标签，输入框与主按钮高度 48px。保留密码显隐、必填校验、请求中状态和中文错误反馈。
- 移除不可操作的“记住密码”和旧英文页脚，不提供尚未实现的注册、短信或自助密码重置入口。
- 用户后续选择浏览器保存密码及管理员重置指引：表单选项行提供默认不勾选的“保存密码”和“忘记密码”。保存请求仅在服务端认证成功后发起，不等待浏览器确认，也不向平台本地存储写入密码；不支持或失败时提示使用浏览器密码管理器，继续正常登录。
- “忘记密码”弹窗指向实际已有的“后台管理 → 用户管理”重置操作，关闭后保留表单，不提供邮件或短信自助重置。
- 窄屏隐藏装饰区，保留顶部品牌和单列表单；短屏允许页面滚动，所有控件均可访问。

`AuthShell.vue` 负责品牌和响应式布局，`LoginView.vue` 保留现有认证、跳转、取消及密码清理逻辑，`browserPasswords.ts` 隔离可选浏览器能力。现有登录测试验证点击、回车、失败重试、保存时序和降级、重置指引及密码不落盘。通过浏览器核对桌面/手机/短屏和正常实例登录；源码热更新，不打包、不修改后端。
