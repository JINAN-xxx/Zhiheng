# 登录页设计

用户选择左右布局，左侧品牌图形、右侧登录。沿用平台的连续白色底色、系统字体和蓝紫主色，以留白组织区域，不设置分割底色、外围登录卡片或大幅英文标语。

- 左上角保留现有智衡标识。桌面左侧为同一标识搭配静态几何线条，辅以“对话 · 智能体 · 知识库”；图形仅装饰，不加载图片、字体或第三方资源。
- 右侧表单宽度约 380px，标题“登录”，账号和密码使用可见标签，输入框与主按钮高度 48px。保留密码显隐、必填校验、请求中状态和中文错误反馈。
- 移除不可操作的“记住密码”和旧英文页脚，表单下方提示“账号由管理员分配”。不提供尚未实现的注册、短信或找回密码入口。
- 窄屏隐藏装饰区，保留顶部品牌和单列表单；短屏允许页面滚动，所有控件均可访问。

`AuthShell.vue` 负责品牌和响应式布局，`LoginView.vue` 保留现有认证、跳转、取消及密码清理逻辑。现有登录测试更新已移除控件的断言，并验证点击、回车、失败重试和密码不落盘。通过浏览器核对桌面/手机/短屏和正常实例登录；源码热更新，不打包、不修改后端。
