# 后台导航整理

用户要求移除后台“若依官网”“首页”入口，并增加返回 AI 工作台按钮。

已在前端导航边界过滤历史官网和首页记录，供路由注册、侧栏、搜索与持久化标签统一使用。保留其他自定义外链；旧 `/index` 地址通过兼容跳转进入当前账号可访问的工作台或管理页面。移除固定首页标签和面包屑中的虚构首页，不修改菜单数据库记录或用户权限。

桌面后台顶部增加可见的“返回 AI 工作台”按钮，移动端使用相同文案。目标由实际可访问路由决定，支持聊天、模型等不同权限组合；没有 AI 路由的账号不显示无效入口。窄屏隐藏重复的顶部页面标题，保留按钮文字。

验证：54 个前端测试文件通过（其中 Node 子测试 9/9）；14 个浏览器辅助测试通过。浏览器覆盖桌面、320/390 像素手机、仅模型权限、仅管理权限、旧 `/index` 链接、登录及权限落地。开发服务器复查曾遇到 `ERR_NETWORK_CHANGED` 导致动态模块加载失败，未放宽断言或自动重试规则；随后使用构建产物重新运行检查通过。

`npm run build:docker` 在独立目录生成静态文件。检查后同步至当前 Nginx 绑定的 `zhiheng-fastapi-frontend/dist`，先复制资源再替换 HTML 入口；通过当前端口 `12580` 的实际静态页面和 mock API 再验证导航，最后清理旧资源。没有重建服务容器、修改后台业务数据或新增镜像包。保留的 `2026.09.30-rc4` 离线包是此前发布验收版本，不包含本次导航修改。
