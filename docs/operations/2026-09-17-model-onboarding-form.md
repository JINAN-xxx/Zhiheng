# 模型接入单页表单发布

现有 8060 平台的模型接入已改为单页抽屉。当前运维入口为 `data/agent-releases/20260917-model-onboarding-form/manage.sh`；后端镜像 `ruoyi-backend-pg:model-onboarding-form-20260917` 基于上一版自动授权修复增量构建。

## 用户流程

打开“接入模型”即可看到模型类型（对话、向量、重排序）、模型名称和显示名称；随后选择服务商及已有连接或新建连接。超时、重试、向量维度及重排序默认参数放在折叠的高级设置中。模型代码和调用别名自动生成并带随机后缀，无需手动填写。

底部统一提供取消、测试连接、接入模型。未保存的凭据可先测试，通过后才允许接入。测试携带明确模型类型，修改连接相关配置会使测试结果失效。开始保存后锁定配置，并自动完成凭据、部署、目录、绑定和发布；失败可在原页重试。关闭重开清除秘密输入并丢弃旧请求和延迟文件读取结果。

## 实现及重试保证

- `CredentialForm` 的嵌入模式复用已有动态字段、文件校验和秘密输入处理，隐藏独立提交按钮。原凭据管理页面继续使用原有独立表单。
- 后端连接测试增加可选 `modelType`，对应 LiteLLM `mode`；旧请求省略或传 null 时保留原契约。
- 部署查询增加可选 `modelAlias`，通过精确查询并复核返回别名，避免只检查默认前 50 条而重复创建。
- 凭据及目录写入结果未知时，重试先查询确认，再决定是否创建；查询失败不会继续写入。绑定结果未知时重新读取当前版本。已有成功资源在同一次接入中复用。
- 不在浏览器存储中保存凭据；公开错误不转发上游秘密内容。已有模型及上一版发布自动同步权限的行为保留。
