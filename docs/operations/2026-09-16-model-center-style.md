# 模型中心桌面风格统一

已按用户指定，以智能体扩展中的智能体、技能页面作为基准，发布模型目录、开发接入和用量记录的桌面样式统一。用户后续要求暂不考虑手机端，最终验收范围为桌面及桌面深色模式。

## 调整

- 页眉采用单行 20px 标题，模型目录标题与侧栏一致；去掉多余副标题和开发接入的重复面板标题。
- 修正模型中心外层容器与扩展页面之间的边距差异。三页采用 20px 外层留白，内容区为 `20px 24px 28px`；知识库页面使用原布局。
- 统一共享字体、语义背景、8px 圆角与轻边框；筛选条、数量信息、圆形刷新与主按钮对齐参考页面。
- 模型和凭据空态使用 WorkspaceState；模型标签采用统一组件样式。开发接入的详情标题、访问密钥和模型授权面板同步调整字号与间距。
- 用量筛选在未选择时显示“全部类型 / 全部状态”占位文本。

## 验证

33 组前端插件测试、Vue 编译、差异检查和 Docker 模式构建通过。最终构建对照桌面及深色页面，智能体、技能、模型目录、开发接入、用量记录的标题字号、实际位置、内容边距和背景均一致；没有横向溢出。

模型接入、模型重新启用、API 说明、应用详情到用量页的桌面组合流程通过。开发服务器组合测试曾发生等待超时，单独场景和最终构建完整流程均通过，没有据此修改业务逻辑。浏览器验收使用隔离接口数据，没有对用户业务数据进行写入。
