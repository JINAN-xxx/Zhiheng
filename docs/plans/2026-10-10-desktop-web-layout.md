# 桌面 Web 布局优化计划

**范围：** `release/platform-integration-merge` 的桌面前端，验收宽度为 1280、1440、1920px。沿用现有主题、权限与 API；调整页面组织和展示，不修改后端业务。用户已确认优化方向并授权实施。

## 实现

- [x] 公共页面：统一桌面标题栏高度、24px 内容边距、36px 常规按钮；消除资源容器与页面的重复内边距。涉及 `AiResourceShell.vue`、`WorkspaceToolbar.vue` 及开发接入/用量页面，沿用 `workspace.scss` 的间距和控件令牌。
- [x] 模型页面：数量、更新时间与刷新放到标题栏；平台模型和凭据视图各只有一个当前视图刷新入口。名称列使用剩余宽度，显示名称与可复制代码分层；图片理解、费率、测试/发布等常用操作使用文字，停用/删除进入更多菜单。保留权限控制、确认弹窗和原 API 行为。涉及模型页及两个列表组件。
- [x] 侧栏：资源页面将最近会话收为可展开入口，进入聊天自动显示历史；展开状态不清空会话数据，不改变工作任务导航和后台返回入口。涉及 `PlatformSidebar.vue`。
- [x] 聊天：模型选择与偏好设置位于对话区域右上角，图片能力和运行状态靠近输入区；不上传图片时使用简短能力标签，具体失败仍给出原提示。保留发送、停止、归档恢复、文件上传与技能选择。涉及聊天页面。

- [x] 检查权限受限账号、长名称、刷新加载/失败、连接测试、模型启停/删除确认、视觉设置和聊天文档/图片能力。
- [x] 运行前端插件测试、相关浏览器回归和 Docker 模式构建；同步版本库中的 dist，并检查构建页面与资源完整性。
