# 后台管理

后台沿用现有账号、角色和接口权限，以五个固定功能分组展示。导航名称和顺序由产品定义，入口随账号权限显示。

| 分组 | 页面与用途 |
| --- | --- |
| 用户管理 | 用户、部门；维护账号及组织归属 |
| 角色权限 | 角色授权、系统内置角色的只读信息 |
| 通知公告 | 公告内容与平台展示开关 |
| 存储管理 | 文件、回收站及存储治理 |
| 系统运维 | 系统状态、在线会话、登录日志与操作日志 |

分组只显示当前账号有权读取的页面。只有部门读取权限的账号进入“用户管理”分组后，只能看到部门；分组不会授予用户账号权限。后台首页进入第一个可访问分组。系统运维优先进入系统状态，无该页权限时使用可访问的子页面。

## 公告展示

有参数读取权限的人员，可在通知公告页查看“在平台展示公告”开关；同时拥有参数写入权限才能修改。公告内容与参数设置仍分别检查权限。仅有参数读取权限的账号通过原 /admin/configs 地址访问公告设置，不会请求公告内容列表。

开关使用原参数 console.notice_enabled。未配置或参数停用时，沿用服务端默认展示规则。修改会启用该参数并保存 true/false，保留版本检查。结果未知时先刷新确认当前状态，再进行下一次修改。

## 操作与表单

列表保留一项主要操作，其余操作放入“更多操作”。删除、重置密码、强制退出等继续执行原确认和权限检查；本人、最后管理员、内置角色及当前会话的保护不变。

输入、密码、数字、单选、多选和状态开关采用统一组件。账号选项加载期间可关闭编辑，保存期间阻止再次提交；版本冲突保留当前输入。角色权限选择保留其他历史代码；菜单、字典和岗位权限已停用，界面不再提交这些代码。

原有业务页面地址继续可用。导航配置、字典及岗位维护页面已移除，旧 /admin/menus、/admin/dictionaries 和 /admin/posts 地址回到后台并进入当前账号有权访问的默认页面。后台界面不再请求菜单投影，历史导航名称、显隐和排序不再控制入口。相关后端接口、CRUD 服务、请求模型与运行时 ORM 映射也已移除，旧接口返回 404。仅保留历史表数据和冻结的迁移脚本，不执行数据删除或数据库迁移。

## 页面切换

后台子页面共用同一个外壳，切换分组不会重建主导航。选中项立即响应，子导航高度和内容采用约 140–160 毫秒的轻量过渡；系统开启减少动画时关闭这些效果。悬停或键盘聚焦时只预加载页面模块，不预取业务数据。

列表读取结果、搜索、分页、日志筛选以及存储筛选和统计状态在当前后台会话内保留。15 秒内返回可复用读取结果，过期后保留原结果并刷新；手动刷新始终重新请求。缓存不延长系统状态的原采集时间，不保存编辑弹窗、密码和文件勾选。离开后台清理缓存；账号或权限变化时清空旧缓存。保存和删除会使相关后台读取缓存失效。

进入后台子页面仍重新核验当前身份和访问权限。路由等待期间保留原内容并暂时禁止操作，超过 140 毫秒显示切换提示；切换失败恢复原页面，连续点击以最后一个目标为准。


## 功能适用范围

用户、角色权限、公告、存储、在线会话、登录/操作日志和系统状态已接入真实业务流程，保留。公告展示开关继续放在公告页，不新增独立通用参数页面。

部门用于维护用户组织资料并在个人资料展示，目前不参与模型、知识库或文件的授权隔离。岗位维护页面、用户编辑中的岗位选择和个人资料的岗位展示已下线。用户接口不再返回或接受 post_ids，个人资料和用户选项不再查询岗位。更新用户资料不会读写历史岗位关联表，存量关联仍保留。

字典没有业务消费者，现已下线后台入口、维护页面和条目抽屉，界面不再读取字典管理数据。角色编辑中不再提供字典、岗位和导航配置的授权选项，存量角色中的旧功能权限不再进入登录权限及角色响应；仅修改角色名称不改写旧权限 JSON，显式修改授权时会清理随旧页面缓存提交的已存储旧代码。新增旧权限仍会被拒绝。只有字典、岗位或导航历史权限的账号不会获得后台入口；同时拥有其他有效后台权限时，只显示对应页面。旧字典、岗位地址按当前账号可用权限回到默认后台页面。历史字典、岗位数据和旧迁移脚本保留，管理接口和运行时代码已删除；不执行数据库迁移或数据删除。


## 后端下线范围

已删除菜单和岗位的通用资源注册、菜单导航投影、字典及条目的路由和服务，以及对应请求/响应模型、公开导出和 ORM 映射。旧接口的列表、详情、创建、修改和删除均不再注册。角色权限目录不再包含六项旧权限。

身份认证每次从有效角色构建当前权限，旧代码不再授权，已有账号和会话可继续使用有效权限。为兼容已保存的角色，角色和用户管理进行权限范围校验时忽略已下线代码；新增授权必须属于当前权限目录。

旧 identity_menus、identity_posts、identity_user_posts、operations_dictionaries、operations_dictionary_items 表仅保留历史数据；它们不再属于应用运行时映射。历史迁移保持原样，当前清理不增加迁移、不删表。
