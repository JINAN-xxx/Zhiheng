# 工作台运行总览

工作台展示真实调用与个人资源动态：快捷入口、今日模型调用、近 7/30 日成功率、今日已确认 Token、本月积分消耗、调用趋势、运行提醒和最近调用资源。数据由 Cookie 接口 `GET /api/overview` 汇总。

## 统计范围和权限

- 进入页面及读取接口需要工作台模块启用、`platform:overview:read`。
- `scope=mine` 只统计本人。用量卡及积分卡还需要用量与调用查看或积分与额度管理查看权限；仅有工作台权限时返回不可用状态，界面显示“—”。
- `scope=platform` 需要独立的 `platform:overview:platform_stats`（工作台下“全平台统计”）操作权限；不因普通工作台访问权自动开放。全平台积分另需 `ai:credits:read`。超级管理员沿用已有显式身份规则。
- 切换全平台统计只扩大聚合指标范围；最近资源、动态和提醒继续按当前用户及各模块查看权限读取。私人助手、技能、应用和 Key 始终属于当前用户，知识库最近使用同时支持当前仍有效的明确共享。共享撤销、模块关闭或资源删除后立即隐藏对应名称与入口。
- 接口不接受目标用户切换，不返回模型凭据、Key 内容、请求/回复正文、助手提示词或技能正文。

角色管理员可以独立勾选全平台统计。现有普通角色不会自动获得新操作，无新增数据库迁移。

## 口径

所有自然日与月份按北京时间（Asia/Shanghai）计算。`days=7` 或 `30` 返回完整日历序列，缺少调用的日期为 0。

- 模型调用数：已有原始用量登记、且已开始请求供应商的模型运行；包含回复、摘要、向量及重排。它不同于提问次数，也不把页面刷新、元数据读取或未执行的预占当作模型调用。
- 成功率：所选周期内成功 /（成功 + 失败 + 中断）。运行中和用户取消不进入分母；没有终态样本时显示“—”。
- 今日 Token：供应商已确认的输入和输出部分之和；缺少完整 Token 的调用单独计数，不按零用量伪造完整结果。缓存及 reasoning 子计数不重复加到输入/输出总数中。
- 本月积分：按调用接纳月份汇总实际结算积分；未知用量单独标注。费用免计后的积分为 0。使用精确十进制字符串，不换算成人民币、不推测供应商账单。计费关闭仍展示历史本月已结算事实，并标注关闭状态。
- 最近调用：来自原始调用、助手审计、知识处理/检索和技能调用快照；资源更新时间不能替代调用时间。当前状态表示启用、发布或索引状态，不声称供应商健康。
- 资源动态：本人当前可访问资源的创建、助手发布、技能创建和知识处理终态。它不是完整的资源变更审计日志。

运行提醒包含本人知识库的进行中任务或未解决失败、近 24 小时失败/中断请求、本人应用下 7 天内到期的 API Key。供应商凭据没有到期字段，因此不生成模型凭据到期提醒，也不虚构处理完成时间或预算进度。

## 刷新和展示

手动刷新或页面重新聚焦且超过 30 秒时重新读取。统计范围、周期或身份变化会中止旧请求，迟到响应不能覆盖新范围。新范围加载时不借用旧用户数据；读取失败显示错误与重试，不把失败伪装成 0。

桌面采用指标卡、趋势与提醒双栏、最近调用与动态双栏；手机端为两列指标和单列内容。调用图支持悬停查看具体日期与次数，资源名称与入口遵循当前权限。
