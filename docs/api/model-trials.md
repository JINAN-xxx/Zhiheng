# 模型独立试用

管理员及启用模型目录、具备查看与 `platform:models:test` 的角色，可在“模型目录 → 模型详情 → 试用模型”输入内容并查看结果。每次试用独立处理，不带入聊天历史、技能、附件或知识库。已启用且连接可用的模型可在此试用；停用模型、停用连接或删除模型均禁止试用。

模型已启用且连接可用后，即可用于与模型类型对应的聊天、智能体、Work、知识库及对外 API，不再需要发布。试用权限只控制目录中的独立测试功能，不额外授予模型管理权限或 API Key 授权。

模型配置读取、编辑、费率与试用权限相互独立。仅有模型读写权限不自动获得试用权限；仅有查看和试用操作的用户可查看可试用模型的基本信息，不能查询凭据、编辑配置或读取费率。角色没有隐式的高低等级，管理员默认具备试用资格，其他角色通过模型目录下“试用与连接测试”（`platform:models:test`）授予。

## API

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | /api/models?trial=true | Cookie 登录且具备试用权限，返回启用且连接可用的模型 |
| POST | /api/models/{id}/trial | 提交用户输入的独立试用，返回 202 RunSnapshot |
| POST | /api/models/{id}/test | 保留原固定内容的连接测试，同样要求登录且具备试用权限 |
| GET | /api/runs/{id} | 所有者查看原任务结果 |
| POST | /api/runs/{id}/cancel | 所有者请求停止原试用 |
| GET | /api/models | 正式模型列表，过滤停用模型及不可用连接 |

trial=true 不授予 include_disabled=true 或凭据读取权限。试用接口使用 Cookie 会话，纯 Bearer API Key 不能调用。正式推理与资源接口不读取此试用开关。

试用请求为 client_request_id（UUID）、prompt（1 至 4000 字符）及 documents（重排序模型专用，1 至 8 份，每份最多 1000 字符）。对话模型输入问题；向量模型输入文本；重排序模型同时输入问题与候选资料。文本不接受空白或 NUL。

同一 client_request_id 和相同内容返回同一任务，改变内容返回 409。试用与固定连接测试使用不同的请求指纹，不能复用同一键发起不同操作。前端未知提交沿用原请求，已知任务恢复只执行读取，不重复调用模型。待确认进度按账号和模型保存在当前标签页 sessionStorage，终态后清除。开始新试用前无法保存进度时不提交。

## 执行与用量

任务沿用既有 Run、Worker 和用量账本，resource_type 为 connection_test，界面统一显示“模型测试”。试用继续受原积分、费率、额度和预占结算规则约束。停止调用按实际完成的用量处理。

接纳时校验试用权限、模型启用状态及连接状态；执行前重新读取账号、角色和模型状态。排队期间失去权限、账号停用、模型或连接停用、模型删除，均在供应商调用前失败并释放预占。模型改绑到其他连接时要求重新试用；已接纳任务保留原冻结凭据修订，不静默换用新连接。

此次无需数据库迁移，现有启用状态、凭据和授权保留。旧数据库的 published 列仅保留历史存储，不参与列表、执行或计费准入。模型管理 API 不再返回或接受 published 参数，也不再提供 publish/unpublish 操作；需要暂时阻止模型使用时应停用模型。

保存前校验读取服务商的 `/models` 目录；不支持目录列表时尝试 `/models/{id}`。只使用该连接已保存的凭据，不跟随重定向；校验有大小和总时限边界，网络请求不持有业务事务。配置提交时复核当前账号权限、模型快照和连接修订，避免校验旧凭据后保存新配置。此校验不生成模型内容，也不产生模型调用用量；实际推理能力仍通过上述独立试用验证。
